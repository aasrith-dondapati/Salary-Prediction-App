# Salary Prediction App

# Overview

This project consists of two main components:

1. `SLR.py` - A Python script that trains a Simple Linear Regression model for salary prediction
2. `app.py` - A Streamlit web application that uses the trained model to make salary predictions

## Tools and Technologies Used

### Core Libraries

1. **NumPy** (`numpy`) - For numerical operations and array handling
2. **Pandas** (`pandas`) - For data loading and manipulation
3. **Matplotlib** (`matplotlib`) - For data visualization and plotting
4. **scikit-learn** (`sklearn`) - For machine learning operations including:
   - `LinearRegression` - The regression model implementation
   - `train_test_split` - For splitting data into training and test sets
   - `mean_squared_error` - For model evaluation

### Model Persistence

- **Pickle** - For saving and loading the trained model to/from disk

### Web Application

- **Streamlit** - For building the interactive web interface

## How It Works

### 1. Model Training (`SLR.py`)

- **Data Loading**: Loads salary data from a CSV file (`Salary_Data.csv`)
- **Data Preparation**:
  - Splits data into features (X - years of experience) and target (y - salary)
  - Splits data into training (80%) and test (20%) sets
- **Model Training**:
  - Creates and trains a Linear Regression model
  - Makes predictions on the test set
- **Visualization**:
  - Generates plots showing the regression line against training and test data
- **Evaluation**:
  - Calculates R² scores for training and test sets
  - Computes Mean Squared Error (MSE) for both sets
- **Model Saving**:
  - Serializes and saves the trained model to `linear_regression_model.pkl` using pickle

### 2. Web Application (`app.py`)

- **Model Loading**: Loads the pre-trained model from the pickle file
- **User Interface**:
  - Provides a number input for years of experience
  - Includes a "Predict Salary" button to trigger predictions
- **Prediction**:
  - Takes user input, converts it to the right format
  - Uses the loaded model to make salary predictions
  - Displays the predicted salary in a user-friendly format

## How to Run the Application

### Prerequisites

- Python 3.x
- Required libraries (install via pip):
  ```
  pip install numpy pandas matplotlib scikit-learn streamlit pickle
  ```

### Running the Model Training

1. Ensure you have the `Salary_Data.csv` file in the correct path
2. Run the training script:
   ```
   python SLR.py
   ```
3. This will:
   - Train the model
   - Generate visualization plots
   - Save the model to `linear_regression_model.pkl`
   - Print evaluation metrics and sample predictions

### Running the Web App

1. After training the model (or using the provided pickle file):
   ```
   streamlit run app.py
   ```
2. The app will open in your default web browser
3. Enter years of experience and click "Predict Salary" to see results

## Sample Outputs

- The training script generates two plots:

  1. Salary vs Experience (Training set) with regression line
  2. Salary vs Experience (Test set) with regression line
- The web app provides interactive salary predictions
